# FashionFinder v4.0 — The Ultimate Edition

Visual Search and Image Retrieval System built on 44,419 fashion products.

## Features
- Image upload search
- URL-based search
- Product ID search
- Style Transfer (same style, new color)
- Style Modifier (formal/casual/sporty/elegant/party)
- Brand Cross-Comparison
- Outfit Completion
- Visual DNA (GradCAM)
- Live Benchmark
- AI Fashion Assistant (RAG + TTS)
